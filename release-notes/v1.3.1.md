## 🔧 NetPulse v1.3.1 — Clean Midnight Handoff

Fixes a rough edge introduced in v1.3.0's midnight handling.

### 🐛 Fixed

**The per-app total jumped up, then collapsed.** The first poll after local midnight both recorded each app's cumulative baseline *and* returned the whole-bucket sum — which still contained yesterday's pre-midnight slice. The next poll switched to the exact `current - baseline` figure, so an app streaming across midnight showed an inflated number that then fell to near zero.

The baseline-capturing poll now reports nothing, and the total grows exactly from that point. No inflated spike, no collapse.

### ✅ Verified

- Lint clean, 26 unit tests, `assembleDebug` and `assembleRelease` green.
- On device after the change: per-app list renders, fresh minute log rows written, no exceptions, stable process.

### 📦 Install

```bash
adb install NetPulse-v1.3.1.apk
```

### ⚠️ Known Limit

The baseline path only engages when the service is alive at midnight; starting later falls back to whole-bucket sums. ReVanced accuracy on the S20 FE remains unmeasured — the device was offline during this release.
