## 🧹 NetPulse v1.3.3 — No Stale Rows

Closes a hole left by v1.3.2's baseline reset.

### 🐛 Fixed

**A re-baselined app kept showing its old total.** Both update sites in `queryTodayTotals` were guarded by `if (bytes > 0L)`. The re-baseline poll deliberately returns `0`, so the guard skipped the write and the map kept the figure computed against the baseline that had just been discarded. Result: a stale total paired with a rate decaying to `0 B/s`.

`recordTotal` now assigns positive values and removes the key on zero, so a re-baselined app's row clears instead of lying. It reappears as soon as real bytes are measured.

### ✅ Verified

- 32 unit tests green (3 new for `recordTotal`).
- Lint clean, `assembleDebug` and `assembleRelease` green.
- Dex inspection confirms the new symbol in the release APK.
