# NetPulse v1.6.0

**Data usage now has history — this week, this month, and all time, not just today.**

### ✨ Added

- **Four usage windows on the Home screen.** The consumption card was hardcoded to today because the app only ever *stored* today: `RETENTION_DAYS = 2` and no code path read a past day. Selecting a window now shows Mobile, Wi-Fi and combined totals for **Today**, **This Week** (trailing 7 days including today), **This Month** (trailing 30 days) and **All Time**.
- **Lifetime counters that survive pruning.** Per-day buckets are bounded storage — the preferences file is rewritten in full on every write and writes happen on the 1 Hz service loop, so retaining every day forever is not viable. All-time therefore comes from separate monotonic `lifetime_mobile` / `lifetime_wifi` counters that the retention sweep never touches.
- **Retention raised from 2 to 35 days** so the month window has real data behind it. The sweep still runs at most once per day.

### 🐛 Fixed

- **The battery guide described Samsung One UI on every device**, including hardware with no Device Care, no Deep Sleeping Apps and no One UI. Copy now lives in a pure `BatteryGuideTexts` object chosen by `isSamsungDevice()`: Samsung devices keep the One UI / Device Care / Deep Sleeping wording, everything else gets generic Android steps (Unrestricted battery usage, background data, keeping the app in Recents). A unit test fails the build if Samsung-specific wording ever leaks into the generic guide.

### ⚠️ Upgrade note

Retention was 2 days before this release, so on the first launch after upgrading only the last couple of days exist. Week and Month fill in as days accumulate; All Time reads from the new lifetime counters, which start at whatever retained days exist on upgrade and grow from there. Nothing is backfilled — that data was never recorded.

### ✅ Verified

- 63 unit tests, 0 failures; 0 lint errors on debug and release.
- Aggregation proven on device with a seeded ledger containing days at 0, 3, 10 and 61 days of age plus lifetime counters above the retained sum. Measured exactly: Today `977 KB / 1.9 MB`, Week `5.7 MB / 1.9 MB`, Month `15.3 MB / 21.0 MB`, All Time `190.7 MB / 381.5 MB`. The 61-day-old bucket is excluded from Month and still counted in All Time, which is only possible via the lifetime counters.
- Chip selection confirmed via `checked="true"` moving between nodes, not just by eye.
- On the non-Samsung emulator the battery guide renders "Battery Optimization" with generic steps and contains **0** occurrences of Samsung / One UI / Device Care / Deep Sleeping.
- A bug found during verification was fixed rather than worked around: the first seed was wiped because the *old* 2-day build pruned it before the new APK was installed. Re-seeding after installing the new build produced the correct numbers.
