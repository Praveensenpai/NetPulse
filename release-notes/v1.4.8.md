# NetPulse v1.4.8

**Today's consumption no longer freezes at midnight, and the usage file no longer grows forever.**

## What changed

- **The counter rolls over live.** Leave the app running past midnight and the
  total resets to the new day on its own. Previously it kept showing yesterday's
  figure until you restarted the app.
- **Old days are cleaned up.** A pair of storage keys was written per day and
  never removed, so the file grew without limit and was fully rewritten on every
  write. Buckets older than yesterday are now pruned automatically.
- **Day keys follow the device clock.** Month, year, and DST boundaries use the
  device's own timezone rules rather than a fixed 24-hour offset.

## How it was proven

Midnight rollover, on a running build with the old code — both days stored at
once, only one visible:

```
usage_2026-11-01_wifi = 168,826,534 B   (160.9 MB, on screen)
usage_2026-11-02_wifi =  21,835,663 B   ( 20.8 MB, invisible)
```

After the fix, same scenario, no restart: the card moved from 160.9 MB to
63.3 MB, matching the stored 66,333,995 B for the new day byte for byte.

Retention, by back-dating the clock and writing traffic on three old days, then
jumping to today:

```
before: usage_2026-10-25_*  usage_2026-10-20_*  usage_2026-10-18_*  usage_2026-11-01_*
after:  usage_2026-11-01_wifi = 21,907,483 B   (20.9 MB on screen)
```

The stale pairs were removed and the surviving value matched the display
exactly.
