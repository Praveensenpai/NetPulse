## 📊 NetPulse v1.2.0 — Per-App Data Usage

Live per-app breakdown and a minute-resolution usage log, with a root-cause fix for missing and frozen counters.

### ✨ What's New

- **🔴 Live App Usage** — a ranked list of which apps are using the network right now, with decaying rates so a burst does not vanish between samples.
- **📜 Usage Log** — a minute-resolution history of per-app bytes, persisted across restarts and capped at 300 entries.
- **🔤 Honest unit labels** — sub-kilobyte usage now renders as `512 B` instead of collapsing to `0 MB`; the status-bar glyph always keeps its unit letter.

### 🐛 Fixed

- **Per-app list empty or frozen.** `NetworkStatsManager` only returns a bucket when it lies entirely inside the queried window, so `end = now` hid the bucket containing the current moment. Queries are now padded past the open bucket, and buckets ending before local midnight are filtered out.
- **Truncated totals.** Whole-day `queryDetails` is silently capped at 100 rows. Per-UID queries replace it, with a rate-limited chunked fallback that subdivides any full window.
- **Invisible sideloaded apps.** `QUERY_ALL_PACKAGES` added so apps like ReVanced appear in the breakdown with real labels.

### 📦 Install

```bash
adb install NetPulse-v1.2.0.apk
```

Then grant Usage Access when prompted — per-app data requires it.
