# NetPulse v1.6.2

**Turning "Pause When Screen Off" off now actually turns it off.**

### 🐛 Fixed

- **The app stayed paused after a screen-off start even with the pause preference disabled.** `onStartCommand` decides whether to begin sampling, and it reads `currentPreferences.pauseWhenScreenOff` — but at that moment the persisted preferences have not loaded yet, so the value is still the in-memory default of `true`. The real preferences arrive a moment later and were stored without ever revisiting that decision.
- **Who hits this:** anyone with *Start on Boot* enabled, on every boot where the screen is still off; also on app update (`MY_PACKAGE_REPLACED`) and on any sticky service restart with the display dark. The service would sit idle until the display was cycled, silently recording nothing.
- **The fix:** every polling decision now goes through a single `applyPolling(screenOn)` helper. `reconcilePolling()` feeds it a live `PowerManager.isInteractive` read, `onScreenStateChanged()` feeds it the broadcast value, and `observeConfiguration()` calls `reconcilePolling()` as soon as the stored `pauseWhenScreenOff` differs from the last value acted on. The rule can no longer be decided from a stale default and then left alone.
- This is the mirror of the v1.4.9 fix, which removed a cached *display* state from the same decision. This release removes a cached *preference* state.

### ✅ Verified

Measured on `emulator-5554` with `mWakefulness=Asleep` throughout, 20,000,206 B of real traffic pulled over Wi-Fi in every case:

| Build | `pause_when_screen_off` | Usage datastore | Bytes recorded |
|---|---|---|---|
| pre-fix | `false` | never created | **0** |
| fixed | `false` | created | **20,664,655** |
| fixed | `true` | never created | **0** |

The first row is the defect: the user asked not to pause, and nothing was recorded. The third row is the negative control — the reconcile honours the preference instead of simply always polling.

66 unit tests, 0 failures; 0 lint errors on debug and release (18 warnings each).
