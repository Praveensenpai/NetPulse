# NetPulse v1.4.7

**Today's consumption no longer freezes at midnight.**

## What changed

- **The counter rolls over live.** Leave the app running past midnight and the
  total now resets to the new day on its own. Previously it kept showing
  yesterday's figure until you restarted the app.
- **Wrong-day reads, not wrong-day writes.** Bytes were being recorded against
  the correct new day all along; only the display stayed pinned to the old
  key. Nothing was lost, it just wasn't visible.
- **Day keys follow the device clock.** Month, year, and DST boundaries all use
  the device's own timezone rules rather than a fixed 24-hour offset.

## How it was proven

Crossed midnight on a running build with the old code. The stored usage file
held both days at once:

```
usage_2026-11-01_wifi = 168,826,534 B   (160.9 MB, on screen)
usage_2026-11-02_wifi =  21,835,663 B   ( 20.8 MB, invisible)
```

After the fix, same scenario, no restart: the card moved from 160.9 MB to
63.3 MB, matching the stored `66,333,995 B` for the new day byte for byte.
