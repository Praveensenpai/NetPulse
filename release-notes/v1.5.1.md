# NetPulse v1.5.1

**The Battery tab no longer has buttons that quietly do nothing.**

### 🐛 Fixed

- **"Open Battery Exemption Settings" flashed and returned with no visible effect when the app was already exempt.** The intent was fine — but Android's `RequestIgnoreBatteryOptimizations` activity has nothing to ask once the app already holds the exemption, so it opens and finishes immediately. The user landed back on the same screen and reasonably concluded the button was broken. The button now checks the exemption first: if it is already held, it renders disabled as **"Battery Exemption Granted"** with a check icon and launches nothing. State is re-read on `ON_RESUME`, so returning from Settings updates it.
- **"Open Samsung Device Care" was shown on every device, including non-Samsung hardware** where neither `com.samsung.android.lool` nor `com.samsung.android.sm` exists. It silently fell through to a generic App Info page while still claiming to be Device Care. `BatteryOptimizer.isSamsungDevice()` existed for exactly this and was never called. The button is now labelled **"Open Samsung Device Care"** only on Samsung, and **"Open App Info"** with an info icon everywhere else.
- `openSamsungDeviceCare()` no longer opens app settings itself as a hidden side effect and no longer reports `false` after doing so; it returns whether a Samsung package was launched, and the caller decides the fallback. `requestIgnoreBatteryOptimizations()` now returns a `BatteryExemptionResult` (`ALREADY_EXEMPT` / `REQUESTED` / `UNAVAILABLE`) instead of succeeding silently.

### ✅ Verified

- Compiles; 50 unit tests green; 0 lint errors on both debug and release.
- On device, A/B reproduced before the fix: with the app exempt, tapping the button started `RequestIgnoreBatteryOptimizations` (`result code=0`) and `topResumedActivity` stayed on `MainActivity` — the screen flashed and vanished. With the exemption removed, the same tap correctly opened *"Let app always run in background?"*.
- After the fix, the full loop was measured: not exempt → button reads **"Open Battery Exemption Settings"** → tap opens the system dialog → **Allow** → `dumpsys deviceidle whitelist` shows `user,com.netpulse.app.debug,10192` → on resume the button reads **"Battery Exemption Granted"**.
- Tapping the granted button afterwards starts **no** settings intent (`grep` count `0`) and leaves `MainActivity` resumed — no dead flash.
- On the non-Samsung emulator the second button renders **"Open App Info"**.
