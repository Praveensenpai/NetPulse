# NetPulse v1.6.5

**Turning off *Show Upload Speed* now hides it from the status-bar icon too, not just the text.**

### 🐛 Fixed

- **The status-bar glyph ignored the *Show Upload Speed* setting.** `SpeedNotificationManager.dynamicIcon()` always formatted `SpeedSnapshot.totalBytesPerSec`, so `showUploadSpeed` reached the notification title but never the icon. On a transfer with little download and a lot of upload — a cloud backup, a photo sync, a large file sent from the phone — the title read `Speed: 0 B/s` while the icon beside it showed the full upload rate. The two surfaces contradicted each other in the same notification.
- **The fix:** a new pure `SpeedSnapshot.displayBytesPerSec(includeUpload)` returns the total when upload is shown and the download half when it is hidden. `dynamicIcon()` now takes `showUpload` and formats that value, so the icon and the title are derived from one rule and cannot drift apart again.

### ✅ Verified

Measured on `emulator-5554` with a live 100 MB upload from the device to a host sink, notification shade open, title read immediately after each screencap:

| `show_upload_speed` | Notification title (live) | Glyph magnitude |
|---|---|---|
| `false` | `Speed: 46.1 KB/s` | `K` (download only) |
| `true` | `↓ 61.8 KB/s   ↑ 2.2 MB/s` | `M` (total) |

The icon glyph was rendered to the shade and read back pixel by pixel: identical position, identical canvas, only the preference changed, and the magnitude letter went from `K` to `M`. Before the fix both runs produced the `M` glyph. R8 mapping in the shipped APK confirms the 3-argument `dynamicIcon(SpeedSnapshot, boolean, boolean)` and `displayBytesPerSec(boolean)` survived shrinking.

77 unit tests, 0 failures; 0 lint errors on debug and release.
