## NetPulse v1.4.5 — Smaller App, Honest Numbers

Two changes: the two usage cards are gone, and the status-bar number is no longer stretched.

### Removed: Live App Usage and Usage Log

Both cards worked. They listed rows, the log was byte-exact, and restart recovery functioned. They still read as broken, because an idle phone shows a column of `0 B/s` and a per-UID netstats sweep takes about 50 seconds to cover every installed app. That is a presentation problem no amount of tuning fixes, so the feature is out.

Gone with it: the tracker, the sweep source, the seed logic, the restart-gap snapshot, the midnight baseline, both test files, and the `PACKAGE_USAGE_STATS` permission. The app no longer asks for usage access at all. Today's total consumption is unaffected and still accurate.

### Fixed: The stretched glyph

`SpeedIconGenerator` was applying a horizontal text scale to squeeze wide labels into the canvas. Height stayed fixed while width shrank, so the digits looked flattened.

It now draws the number and a smaller unit as two separate runs at natural width, and shrinks both uniformly only if the pair overflows. Sizing is taken from measured digit ink (`getTextBounds`) instead of `fontMetrics`, whose ascender and descender padding had been leaving the number at roughly half the canvas height.

Measured on `emulator-5554`: ink box **39×28 px**, height level with the clock's cap height, no horizontal compression.

### Verified

- 17 unit tests, 0 failures
- Lint 0 errors, `assembleDebug` and `assembleRelease` green
- Glyph measured and inspected at 10× zoom on the installed debug build
- Home screen confirmed free of both cards on device
